# Introduction-page screenshots

Screens for the before/after comparison of the introduction site ([docs/sites](../sites/README.md)). As an exception to `AGENTS.md`'s "screen captures are not committed" rule, **this folder only** holds introduction scenes at small sizes (the user's decision, 2026-10-23, issue #23). (The table above lists each file, its scene and its source: reJSRF v0.0.48 captures by the user on 2026-10-23.)

* The window frame is cropped to the game picture (1280×960), scaled to a 960×720 JPEG (quality 90).
* The game screens belong to SEGA; only the few scenes needed to introduce the fan translation are used.
* More scenes are captured directly with reJSRF (menus, mission objectives, event subtitles); adding a file also adds its comparison to `docs/sites/static/index.html`.
