8. `tools/patch.py`: 검증 → 글꼴 → 문장 → XBE → 출력(하드링크/복사) → `--iso` → `md5.txt`. `--identity`, `--update-manifest`.
9. 검증: 설계 §4의 1~6.

# Work order: deliverable format and patcher skeleton (issue #2, P1)

Design: [20261021-i002](../design/20261021-i002-patcher.md)

1. The `tools/jsrfkr/` package: `xbe.py` (the existing analysis module + section digests), `encode.py` and `xiso.py` (moved from the proof of concept), `digest.py`. Remove the old modules and change the imports in `tools/analysis/`, `tools/font/` and `tools/poc/`.
2. Module-move check: the outputs of `build_font.py`, `build_poc.py` (`--identity` and the default), `font_tables.py` and `renderer_compare.py` are unchanged.
3. `tools/jsrfkr/container.py`: `parse`, `build`, lookup by item path; malformed input raises.
4. `tools/jsrfkr/textpatch.py`: TSV reading (`off:`, `va:`, `norm:`), duplicate checks, in-place replacement.
5. `tests/`: unit tests for the container, TSV and encoder (`python -I -m unittest discover tests`).
6. `tools/check_roundtrip.py`: round trip of every `MULT`/`NORM` file in the dump and of the XBE digests.
7. `patch/manifest.json`, `patch/text/` (a note for the empty folder), `patch/xbe/` (a format note).
8. `tools/patch.py`: checks → font → text → XBE → output (hard links or copies) → `--iso` → `md5.txt`; `--identity`, `--update-manifest`.
9. Verification: items 1–6 of design §4.
10. Documents: `tools/README.md` (an overview of the tools), `docs/analysis/containers.md`, the analysis index, `docs/guides/` (a guide to applying the patch), the P1 section of `handoff-rejsrf.md`, PLAN §4, the work log.
