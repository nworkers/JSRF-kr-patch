# Work order: GitHub Actions releases and the distribution package (issue #22, P9-1)

Design: [20261023-i022](../design/20261023-i022-release.md)

1. `release/README.md`: the package user-guide template (Korean + English; usage; sources, licenses and rights notice).
2. Code: executable paths (design §8.3). `tools/release.py`: module collection (`modulefinder`), the Python zip, the Nuitka build (pinned 2.8.10, `tools/release-requirements.txt`), per-OS packages (with `licenses/`), `SHA256SUMS.txt`, self-check; the executable section of `THIRD_PARTY_NOTICES.md`.
3. `.github/workflows/ci.yml` (tests + package artifact), `.github/workflows/release.yml` (tag or manual → GitHub Release).
4. Tests: unit tests for `release.py`'s file list and determinism (no game data).
5. Verification: determinism, the self-check, package + dump → `default.xbe` and xiso MD5s equal to the repository output, a CI run.
6. Documents: `tools/README.md`, `docs/guides/apply-patch.md` (using the release package), PLAN P9, the work log.
