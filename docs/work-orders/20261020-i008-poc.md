# 작업 지시: 개념 증명 (issue #8, P4)

설계: [20261020-i008](../design/20261020-i008-poc.md)

1. `tools/poc/encode.py`: 한국어(UTF-8) → 게임 바이트열(P3 고정 대응, 공백 `0x20`, 남긴 기호·영문 칸). 표에 없는 글자는 거부.
2. `tools/poc/xiso.py`: XDVDFS 볼륨·디렉터리 읽기, 경로로 파일 찾기, 같은 크기 덮어쓰기.
3. `patch/poc/lines.tsv`: 설계 §2의 자리, 원문 길이·SHA-1, 한국어.
4. `tools/poc/build_poc.py`: 입력 검증 → 글꼴(P3 모듈) → 제자리 교체·섹션 요약값 → xiso 복사·교체 → reJSRF 폴더(US XBE 표 패치, 하드링크) → MD5 목록. `--identity` 왕복.
5. 검증: 왕복, 차이 범위, xemu 캡처(사용자와 함께), reJSRF 실행.
6. 문서: 분석(미션 파일 문장 구조, 화면 결과), 인계 문서, 도구 README, 작업 로그.

# Work order: proof of concept (issue #8, P4)

Design: [20261020-i008](../design/20261020-i008-poc.md)

1. `tools/poc/encode.py`: Korean (UTF-8) → game bytes (fixed P3 mapping, space `0x20`, kept symbol and Latin cells); refuses characters not in the table.
2. `tools/poc/xiso.py`: read the XDVDFS volume and directories, find a file by path, overwrite it at the same size.
3. `patch/poc/lines.tsv`: the places of design §2, original length and SHA-1, Korean.
4. `tools/poc/build_poc.py`: input checks → font (P3 modules) → in-place replacement and section digests → xiso copy and replacement → reJSRF folder (US XBE table patch, hard links) → MD5 list; `--identity` round trip.
5. Verification: round trip, changed ranges, xemu capture (with the user), reJSRF run.
6. Documents: analysis (mission-file text structure, screen results), handoff, tool README, work log.
