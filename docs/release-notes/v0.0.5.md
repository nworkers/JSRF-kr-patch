## JSRF-kr-patch v0.0.5

issue #8(P4)의 결과입니다. **한국어가 실제 게임 화면에 나왔습니다.** P3 글꼴(글리프 표 데이터 패치와 새 `jetfont.dat`)과 제자리 문장 교체만으로, 미션 목표·메뉴·대화 한 줄씩을 Cxbx-Reloaded, xemu, reJSRF에서 확인했습니다. 넣은 문장은 시험 문장이며 아직 번역은 없습니다.

### 바뀐 것

* **설계**([20261020-i008-poc.md](../design/20261020-i008-poc.md)): 길이를 바꾸지 않는 제자리 교체, xemu용 xiso 사본, reJSRF용 게임 폴더.
* **개념 증명 도구**(`tools/poc/`, 표준 라이브러리만): `encode.py`(한국어 → 게임 바이트열), `xiso.py`(XDVDFS 읽기·같은 크기 덮어쓰기), `build_poc.py`. 사용법은 [tools/poc/README.md](../../tools/poc/README.md).
* **시험 문장**: `patch/poc/lines.tsv` 7줄(원문 없이 위치·길이·SHA-1·한국어).
* `tools/font/build_font.py`를 함수로 나눴다(출력은 같다).
* **분석**: [text-files.md](../analysis/text-files.md)(미션 파일, 대화 이벤트, XBE 메뉴 표, 일본판 언어, HDD 캐시). [text-renderer.md](../analysis/text-renderer.md)의 "표에 없는 코드" 화면을 확인됨으로.
* **가이드**: [emulator-check.md](../guides/emulator-check.md)(출력 만들기, HDD 캐시 지우기, 에뮬레이터별 실행).
* reJSRF 인계 문서에 P4 절.

## JSRF-kr-patch v0.0.5

The result of issue #8 (P4). **Korean appears on the real game screen.** With the P3 font (a glyph-table data patch and a new `jetfont.dat`) and in-place text replacement alone, one mission objective, one menu line and one talk line were checked in Cxbx-Reloaded, xemu and reJSRF. The lines are test lines; no translation yet.

### Resolved issues

| Issue | Content | Commits |
|---|---|---|
| [#8](https://github.com/nworkers/JSRF-kr-patch/issues/8) | Proof of concept: one mission line and one menu line in Korean | `d9c4286`, `f35ee81`, `71dbfe8`, `0e2ef45`, `5e5785d`, `18ab081`, `4b5286e` |

### Changes

* **Design** ([20261020-i008-poc.md](../design/20261020-i008-poc.md)): same-length in-place replacement, an xiso copy for xemu, a game folder for reJSRF.
* **Proof-of-concept tools** (`tools/poc/`, standard library only): `encode.py` (Korean → game bytes), `xiso.py` (XDVDFS reading, same-size overwrite), `build_poc.py`; usage in [tools/poc/README.md](../../tools/poc/README.md).
* **Test lines**: seven in `patch/poc/lines.tsv` (place, length, SHA-1 and Korean; no original text).
* `tools/font/build_font.py` split into functions (same output).
* **Analysis**: [text-files.md](../analysis/text-files.md) (mission files, talk events, XBE menu tables, the Japanese build's language, the HDD cache); the "missing code" screen in [text-renderer.md](../analysis/text-renderer.md) marked confirmed.
* **Guide**: [emulator-check.md](../guides/emulator-check.md) (building the output, clearing the HDD cache, running each emulator).
* A P4 section in the reJSRF handoff.

### Checks

|---|---|

| Cxbx-Reloaded | Roboy's line, the first mission's objective and the pause menu's "저장" show in Hangul |
