## JSRF-kr-patch v0.0.6

The result of issue #2 (P1). **There is now a proper patcher, `tools/patch.py`, and a patch data format.** Run it on your own dump to make a patched game folder (and xiso). There is no translation yet, so the output is for testing.

### Resolved issues

| Issue | Content | Commits |
|---|---|---|
| [#2](https://github.com/nworkers/JSRF-kr-patch/issues/2) | Deliverable format design and patcher skeleton | `7b872f8`, `993c5f4`, `876b0de`, `f35caa0`, `43bbbcc` |

### Changes

* **Design** ([20261021-i002-patcher.md](../design/20261021-i002-patcher.md)): the command line, the patch data format, verification; the output copies by default, with hard links under `--link` (the user's decision).
* **Patcher** `tools/patch.py`: input MD5 checks → font → text → XBE → output folder → `md5.txt`; `--iso`, `--identity`, `--update-manifest`.
* **Shared package** `tools/jsrfkr/`: `xbe`, `container` (`MULT`/`NORM`), `encode`, `textpatch`, `xbepatch`, `digest`, `xiso`; the analysis, font and proof-of-concept tools now use it.
* **Patch data**: `patch/manifest.json`, `patch/text/*.tsv` (`off:`, `va:`, `norm:` places), `patch/xbe/*.json` (format only).
* **Analysis**: [containers.md](../analysis/containers.md) (the `MULT`/`NORM` format; event text sits in item `2/0` of `e###.dat`, with the NUL terminator outside the item length).
* **Tests**: `tests/` (14, no game data), `tools/check_roundtrip.py` (whole-dump round trip, output folder comparison).
* **Guide**: [apply-patch.md](../guides/apply-patch.md); [tools/README.md](../../tools/README.md), the README usage, a P1 section in the reJSRF handoff.
