### 바뀐 것

* **설계**([20261021-i013-text-reinsert.md](../design/20261021-i013-text-reinsert.md)): 묶음별 방법, 페이지 수는 바꾸지 않음(사용자 승인), XBE 새 섹션, 화면 제한 검사.
* **재삽입** `tools/jsrfkr/reinsert.py`: 이벤트·대화는 페이지를 바꿔 다시 만들고(공백 채움 없음), 미션은 파일 끝에 붙이고 포인터를, XBE는 새 섹션 `KRTEXT`로 옮기고 `.data` 칸·`push` 즉치를 고친다.
* **XBE 편집** `tools/jsrfkr/xbeedit.py`: 섹션 머리 표를 옮겨 섹션을 더하고, 이미지 자신의 표로 요약값을 계산한다.
* **화면 검사** `tools/jsrfkr/screen.py`: 페이지·분기 코드 수가 원문과 같은지, 페이지 버퍼(멈춤), 줄 폭·줄 수(경고).
* **xiso**: 커진 파일을 이미지 끝에 쓴다.
* **검사 도구** `tools/check_reinsert.py`: 원문 왕복과 옮기기 왕복.
* **시험 문장** `patch/poc/long.tsv`, 단위 시험 48개.
* **가이드**: [text-pipeline.md](../guides/text-pipeline.md) §2.2·§4·§5, [emulator-check.md](../guides/emulator-check.md) §5, [apply-patch.md](../guides/apply-patch.md) §3(P4 시험 문장의 `TE014.bin` MD5가 바뀜).

## JSRF-kr-patch v0.0.8

The result of issue #13 (the second half of P5). **Korean longer than the original can now go in**, with the translation file format unchanged. No emulator screen check yet (issue #13 stays open for it).

### Resolved issues

| Issue | Content | Commits |
|---|---|---|
| [#13](https://github.com/nworkers/JSRF-kr-patch/issues/13) | Reinserting text whose length changes (P5-2); screen check pending | `e7e4a6f`, `c3417ae`, `5ed9d6f` |

### Changes

* **Design** ([20261021-i013-text-reinsert.md](../design/20261021-i013-text-reinsert.md)): the method per group, page counts unchanged (approved by the user), a new XBE section, screen-limit checks.
* **Reinsertion** `tools/jsrfkr/reinsert.py`: event and talk pages are replaced and rebuilt (no padding), mission strings appended with their pointers fixed, XBE strings moved into a new section `KRTEXT` with their `.data` slots and `push` immediates fixed.
* **XBE editing** `tools/jsrfkr/xbeedit.py`: moves the section header table to add a section; computes digests from the image's own table.
* **Screen checks** `tools/jsrfkr/screen.py`: page and branch codes as in the original, the page buffer (stop), line width and line count (warnings).
* **xiso**: grown files are written at the end of the image.
* **Check tool** `tools/check_reinsert.py`: the original and move round trips.
* **Test lines** `patch/poc/long.tsv`; 48 unit tests.
* **Guides**: [text-pipeline.md](../guides/text-pipeline.md) §2.2, §4, §5; [emulator-check.md](../guides/emulator-check.md) §5; [apply-patch.md](../guides/apply-patch.md) §3 (the P4 test lines' `TE014.bin` MD5 changes).
