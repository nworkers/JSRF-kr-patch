## JSRF-kr-patch v0.0.9

The result of issue #15 (P6-0). **Translation is ready to start**: a glossary, a translation check tool and a translator guide, and a first pass of 544 XBE menu, notice and name rows in the default patch. The game dialogue is translated by people (P6-1 on).

### Resolved issues

| Issue | Content | Commits |
|---|---|---|
| [#15](https://github.com/nworkers/JSRF-kr-patch/issues/15) | Translation preparation: glossary, first pass of XBE functional strings, translation tools and guidelines (P6-0) | `4931dcd`, `441c5a2`, `600affe` |

### Changes

* **Design** ([20261021-i015-translation-prep.md](../design/20261021-i015-translation-prep.md)): scope, dialogue by people (a copyrighted work), the check tool, the glossary format.
* **Check tool** `tools/check_text.py`: every error and warning, progress and the Hangul syllable count without output; `--review` writes side-by-side tables under `work/` (Japanese, English, Korean with term hints, codes to keep, line limits).
* **Glossary** [docs/kb/glossary.md](../kb/glossary.md): spelling rules, 119 terms, usable symbols.
* **Translator guide** [docs/guides/translation.md](../guides/translation.md).
* **Patch data**: `event.tsv` `talk.tsv` `mission.tsv` `xbe.tsv` in `patch/text/`, with a first pass of 544 functional rows in `xbe.tsv` (7 rows longer than the original move to the new section).
* **Encoder**: the full-width space (U+3000) can be used.
* Shared steps `tools/jsrfkr/pipeline.py`, glossary reading `glossary.py`; PLAN P6 updated.
