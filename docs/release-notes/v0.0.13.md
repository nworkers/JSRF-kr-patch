## JSRF-kr-patch v0.0.13

The results of issues #22 (P9-1) and #23 (P9-2). **From this release the patch can be downloaded straight from GitHub Releases**: standalone executables for Windows and Linux (no Python needed) and a Python-script edition, plus an introduction page at <https://nworkers.github.io/JSRF-kr-patch/>.

| [#23](https://github.com/nworkers/JSRF-kr-patch/issues/23) | Patch introduction page: hip-hop/graffiti theme, features, before/after screenshots, translation, downloads | `205b786`, `ec467f7`, `0cd1188`, `914af97` |

### Changes

* **Release packages** (`tools/release.py`): `jsrf-kr-patch-v0.0.13-windows-x64.zip`, `-linux-x64.tar.gz` (standalone executables built with Nuitka 2.8.10, patch data inside), `-python.zip` (the script edition), `SHA256SUMS.txt`; each package has a user guide (usage, sources, rights notice) and license texts; packages are deterministic and self-checked.
* **Workflows**: `ci.yml` (tests and the three packages), `release.yml` (tag push → GitHub Release, resolved issues checked in the notes), `pages.yml` (introduction page, download buttons refreshed after a release).
* **Nuitka pinned to 2.8.10**: from 4.0 it is AGPL-3.0, so the last Apache-2.0 release is used; an executable-distributions section in `THIRD_PARTY_NOTICES.md`.
* **Patcher**: data and font paths and the output location (`out/` in the current folder) in the executable; script behaviour unchanged.
* **Introduction page** (`docs/sites/`, `tools/site/build_site.py`): features, before/after (reJSRF captures), translation, downloads (latest release), usage, release timeline; screenshots in `docs/screenshots/` (exception stated in `AGENTS.md`).
