## JSRF-kr-patch v0.0.7

The result of issue #11 (the first half of P5). **The formats of the four places holding on-screen text are confirmed, and there is now a text extraction tool, `tools/extract_text.py`, a translation skeleton, and a step-by-step guide that can be followed without AI.** Reinsertion of Korean longer than the original is the next issue.

### Resolved issues

| Issue | Content | Commits |
|---|---|---|
| [#11](https://github.com/nworkers/JSRF-kr-patch/issues/11) | Text-format analysis and extraction (P5-1) | `3e2ac30`, `053a9d0`, `6e83027` |

### Changes

* **Design** ([20261021-i011-text-extract.md](../design/20261021-i011-text-extract.md)): what to recompute when a length changes, text units and places, the output format, what reinsertion needs.
* **Analysis**: [message-script.md](../analysis/message-script.md) (event item `2/0` and talk events share one format; the header's page counts split the text; branch arguments are page numbers), [mission-files.md](../analysis/mission-files.md) (loader `0x25DD0`, relocation `0x4DB30`, the 7 per-language pointers of text commands, longer strings appended at the end), [xbe-strings.md](../analysis/xbe-strings.md) (651 in `.rdata`, 1,083 `.data` slots, 23 `push`es); unresolved items of `text-files.md` and `containers.md` settled.
* **Extraction tool** `tools/extract_text.py`: 2,276 text units (events 397, talk 733, missions 495, XBE 651) with places, SHA-1s and originals into `work/text/`, and skeletons without original text into `work/text/skeleton/`.
* **Modules** `tools/jsrfkr/`: `msgscript`, `mission`, `xbetext`, `extract`; `textpatch` skips rows with an empty `korean` (untranslated = original kept).
* **Guide**: [text-pipeline.md](../guides/text-pipeline.md) (extract → translate → reassemble); `AGENTS.md` gains the rule "guides are written to be followed without AI, and a task changing a tool or step updates them".
* **Tests**: 27 unit tests (no game data).
