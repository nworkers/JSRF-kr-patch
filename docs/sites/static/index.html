영어판 위에 한국어

게임은 영어판으로 돌고, 영어가 나오던 자리에 한국어가 나온다. 음성과 그림은 영어판 그대로.

The English game, with Korean where the English was. Voices and art unchanged.

잘리는 문장 없음

Longer translations still show in full.

게임에 어울리는 한글

배민 도현체로 한글을 새로 그려 넣었다. 게임 프로그램은 고치지 않는다.

Hangul drawn in the Do Hyeon font. The game's program is not changed.

게임 파일은 안 들어 있다

No game data inside. You apply it to your own copy of the game.

  • 길거리 말투 번역투를 걷어 내고, 인라인과 그래피티의 거리에 어울리는 젊고 가벼운 구어체로.

사용법How to patch

  1. 1

    내려받기

    내려받기에서 내 OS에 맞는 묶음을 받아 푼다. 실행 파일판은 Python이 필요 없다.

  2. 2

    덤프 준비

    직접 가진 디스크의 덤프: default.xbe(US판, MD5 f4e366bf…)와 Media/ 폴더, 그리고 ISO를 만들려면 xiso.

  3. 3

    한 줄 실행

    jsrf-kr-patch.exe "D:\dump\Jet Set Radio Future" out\jsrf-kr --iso "D:\dump\JSRF.iso"
    ./jsrf-kr-patch "/path/Jet Set Radio Future" out/jsrf-kr --iso "/path/JSRF.iso"
    python -I tools/patch.py "/path/Jet Set Radio Future" out/jsrf-kr --iso "/path/JSRF.iso"

    결과: out/jsrf-kr/(패치된 게임 폴더)와 out/jsrf-kr.iso. xemu는 ISO를, Cxbx-Reloaded는 default.xbe를 연다.
